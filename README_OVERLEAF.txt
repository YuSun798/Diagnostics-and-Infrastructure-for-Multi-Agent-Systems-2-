Frontiers in Computer Science - Review article
Diagnostics and Infrastructure for Foundation Model-Based Multi-Agent Systems

HOW TO BUILD IN OVERLEAF
1. Upload this zip as a new project (New Project -> Upload Project).
2. Set the main document to: frontiers_main.tex
3. Compiler: pdfLaTeX, then recompile once more (references.bib and a
   pre-built main.bbl are both included, so citations resolve either way).
